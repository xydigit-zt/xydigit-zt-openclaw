## Overview

Add an `openclaw skills uninstall <slug>` CLI command that cleanly removes a ClawHub-installed skill from the active workspace. Mirrors the existing `openclaw skills install` flow and the `plugins uninstall` pattern.

## Scope

- **In scope**:
  - Workspace directory removal (`~/.openclaw/workspace/skills/<slug>/`)
  - Lockfile entry cleanup (`.clawhub/lock.json`)
- **Out of scope** (Non-goals):
  - Sandbox copies (auto-reconciled on next agent start)
  - Bundled skills and dashboard UI
  - `openclaw.json` mutation
  - `--all` / multi-slug / wildcard
  - Trash / undo

## CLI Surface

```
openclaw skills uninstall <slug>
  [--dry-run]     show what would be removed, no changes
  [--yes]         skip confirmation prompt
  [--json]        machine-readable output
  [--global]      uninstall from shared managed skills directory
  [--agent <id>]  target agent workspace
```

## Implementation

- `src/skills/lifecycle/clawhub.ts`: Added `planSkillUninstall` and `executeSkillUninstall` functions
- `src/cli/skills-cli.ts`: Added `uninstall` command after `install`

## Acceptance Criteria

1. `openclaw skills uninstall <slug>` removes workspace dir and lockfile entry
2. `--dry-run` shows plan without executing
3. `--yes` skips confirmation
4. `--json` outputs valid JSON
5. Unsafe slugs are rejected with error
6. Non-existent skill exits 0 with "not installed" message
7. Directory removal failure is logged as warning, lockfile still cleaned
